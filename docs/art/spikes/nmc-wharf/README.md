# The wharf you disappear under, and the edges that were never faced

Plates for **#734**, shot from the running game at its own framing (`live-editor-plate-recipe`).

Every pair is **top = before, bottom = after**, the same frame at the same clock on the same
freshly-placed dressing: the "before" arm puts the quay face back on a lip-anchored `YSortSprite` and
drops the three new runs, so the pair is an A/B of that PR and not of two months of other merges.

**The measurement that shaped the fix:** the wharf is a fill, deck +3.00 m over a −1.60 m shoal, so
*every* edge of it is a 4.60 m wall. Walked as a perimeter on the built terrain, three of them had no
run at all — the wharf head 6.5 m, the apron's west side 47.5 m, its south end 9.5 m: **63.5 m**. The
junctions the charter named were fine; the runs cross past the L in both directions.
