# Goods handling delivery order

**Proposed backlog, no new roadmap milestone or implementation authorization.** Read the roadmap's [current snapshot and M1 re-scope](../../roadmap.md#05-where-we-are--snapshot-2026-09-01-regenerate-at-every-coordinator-handoff) before its older Coddle Cove narrative. St Peters' existing playable arc includes freshness, freezer, traps and the earned dory; its gate was called GO. “M1” below is a bounded repair of that playable arc, not reopening its verdict or pulling industrial logistics into it. P4 requires hand work before later delegation; P5 requires clear, recoverable refusals.

The ordered implementation proposals, owning roles, dependencies and exact acceptance are in [proposed goods backlog](../../../backlog/proposed-goods-handling.md). The current source audit is [00-today](00-today.md); all later descriptions are design, not shipped state.

No implementation item edits a file currently held by another open lane. At each start, re-read live ownership: catch-honesty code was in PR 1033, the wharf scene/builders in PR 1039, ground blends in PR 1036 at this audit. Design against Core seams or schedule an owner handoff; do not duplicate their changes. Art roles own the rig source, sprite fill and contact/look acceptance. Proposed charters are future work orders, not permission for a headless logic lane to judge or change a look.

Budget shape: M1 adds a small engine-light authority plus migration and adapters; it does not solve arbitrary 3D packing or simulate per-fish physics. M2 adds placements/carriers incrementally. M3 machines require new art, import, controls, route and payload work; they are not “one more vehicle Def”. Every phase keeps a playable manual path and ships meaningful logic/integration tests plus its owning roles' editor proof.
