The wheel on the boat is not this sprite rotated — at 0.35 m it is eleven pixels seen at 40°, so it is built as geometry on the console's aft face and baked into the hull's own cell at the hull's own pivot, like the oar and motor layers. Spin turns the spokes about the column axis in 3D; the same rock(i) values that move the hull move the wheel, so it never floats off the console. Heading answers only with way on.
