Static panel; the game drives every moving part as a parameter. The wheel turns 1:1 off the helm, the needles sweep from RPM & fuel state, and the single binnacle lever swings on its arc — ahead is full speed forward, centre is neutral, aft is reverse (one control for throttle and F–N–R shift). Painted surfaces — face, sheer band, cove pin, wheel cap — come off the boat's own colourway; the bought-in instruments stay graphite on every hull.
Diegetic only
In-world UI is only real things that carry it. The bare dory shows one tiller; a rigged console earns the whole dash — gauges, wheel, lever, switches — because the boat actually has those systems.
